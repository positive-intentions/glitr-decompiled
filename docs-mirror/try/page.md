# Try Glitr

The app is the product: Open Glitr. These pages open one layer at a time so you can feel messaging, storage, and encryption without reading a protocol spec.
Each link is a real experience in the browser. None of them require you to clone source. The Signal Protocol page is the only one that also offers source code.

## Start here​

Messaging — Talk now (two tabs + Pair now) or two mailboxes, ticks, poll, optional live.
Live link — two browsers, a handshake, a direct data path for text and files.
Your storage — git as the place files actually live.

## Then the locks​

Encrypted records — structured documents on git, with fields you can seal.
Encryption tools — the primitives behind the password envelope.
Post-quantum — ML-KEM and PQXDH.
Signal Protocol — the open handshake library.
If you already know you just want to talk to one person, skip this section and use Talk now or Your first conversation.
